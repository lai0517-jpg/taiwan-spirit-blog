# 資料參考｜References

這個資料夾用來放《台灣靈格》部落格後續整理、查證、製作地圖與補充文章時需要參考的原始資料。

## 建議放置方式

- `地區資料_Regions/`：地區分區、縣市、文化區域、地景脈絡。
- `台灣地圖_Map/`：地點、地址、座標、地圖點位、路線資料。
- `廟宇神靈_Temples/`：廟宇、神明、祭典、家將、地方信仰故事。
- `精怪地景_Monsters/`：精怪、傳說、地景禁忌、地方故事。
- `法器符咒_Talismans/`：法器、符令、紙錢、祭儀用品、實物參考。
- `植物作物_Plants/`：植物、作物、族群使用、民俗用途、生態資料。
- `圖片參考_Image_References/`：照片、掃描圖、圖片來源註記、視覺參考。

## 檔名建議

請盡量使用中英文並列，方便日後整理與搜尋。

範例：

```text
台南大天后宮_Tainan_Grand_Matsu_Temple.md
王船祭_Wangye_Boat_Festival.pdf
臺灣百合_Taiwan_Lily.jpg
```
